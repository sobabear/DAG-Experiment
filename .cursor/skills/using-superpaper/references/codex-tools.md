# Codex Tool Equivalents

When running SuperPaper skills in Codex, use these tool equivalents in place of Claude Code tool names.

| Claude Code Tool | Codex Equivalent |
|------------------|------------------|
| `Bash` | `shell` |
| `Read` | `read_file` |
| `Write` | `write_file` |
| `Edit` | `patch_file` |
| `Glob` | `list_files` |
| `Grep` | `search` |
| `Skill` | N/A — paste skill content directly |

Refer to Codex documentation for the full list of available tools and their parameters.
