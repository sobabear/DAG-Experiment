# Gemini CLI Tool Equivalents

When running SuperPaper skills in Gemini CLI, use these tool equivalents in place of Claude Code tool names.

| Claude Code Tool | Gemini CLI Equivalent |
|------------------|-----------------------|
| `Bash` | `run_in_terminal` |
| `Read` | `read_file` |
| `Write` | `write_file` |
| `Edit` | `replace_in_file` |
| `Glob` | `find_files` |
| `Grep` | `search_files` |
| `Skill` | `activate_skill` |

Refer to Gemini CLI documentation for the full list of available tools and their parameters.
