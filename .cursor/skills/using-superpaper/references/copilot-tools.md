# Copilot CLI Tool Equivalents

When running SuperPaper skills in Copilot CLI, use these tool equivalents in place of Claude Code tool names.

| Claude Code Tool | Copilot CLI Equivalent |
|------------------|------------------------|
| `Bash` | `run_terminal_command` |
| `Read` | `read_file` |
| `Write` | `write_file` |
| `Edit` | `edit_file` |
| `Glob` | `list_directory` |
| `Grep` | `search_files` |
| `Skill` | `skill` |

Refer to Copilot CLI documentation for the full list of available tools and their parameters.
